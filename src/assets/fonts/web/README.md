Latin-subset woff2 files for the site's web fonts, served through Astro's `experimental.fonts` (local provider) in
`astro.config.mjs`. Downloaded from Google Fonts on 2026-09-19. All four families are licensed under the SIL Open
Font License 1.1. To add a weight: download it with the script in `docs/plans/pagespeed-render-blocking-*-plan.md`
and add the face to the family's list in `astro.config.mjs`.
